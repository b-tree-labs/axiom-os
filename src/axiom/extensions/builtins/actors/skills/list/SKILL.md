# actors.list

Reads across the gate's accounts, keys and invitations, the directory's groups,
the agent roster and this node. Stores nothing. A person outside the asker's
site scope is not listed and not counted. Which fields each row carries follows
the asker's role: members see name, handle, kind, roles and contact buttons;
stewards also see status and groups; administrators also see the address, keys
and pending invitations.
