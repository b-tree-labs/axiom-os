THE ASYMMETRY NOBODY WOULD GUESS
Guidance reaches thirteen harnesses through their own rules files. Runs come back from about seven. For the rest we can change how an agent behaves and never see whether it did, which is the wrong way round and has to be visible on the row rather than discovered later.
MEMORY IS THE SAME OBJECT, NOT A SECOND SURFACE
A session is a run and what it remembered is what the run produced, so reviewing memory is opening a row. The corpus, the origin, the dedup and the gate that decides what may be shown are the ones already built for portable memory. Asking memory a question is the Done facet with a different query.
